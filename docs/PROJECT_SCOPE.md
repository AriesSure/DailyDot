# DailyDot AI Upgrade Scope


## Goal

Transform DailyDot from:

AI-enabled web application

into:

AI Application / Agent workflow demonstration project.


## Final Capabilities

The project should demonstrate:

1. RAG-based recommendation
2. Reliable tool calling
3. User context utilization
4. Bounded agent workflow
5. AI testing


## Out of Scope

- Multi-agent
- Autonomous agent
- AI platform
- Model training
- Vector infrastructure
